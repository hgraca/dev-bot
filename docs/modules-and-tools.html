Dependency Details

Each card shows a module and the other modules it explicitly references in its skill files, agent definitions, or tool implementations.

devteam

Multi-agent planning and implementation workflow. TeamLead orchestrates 8 subagents through structured plan→implement→review cycles.

Depends on: agent-communication explore · gather-context memory · search-memory format-md dev · documentation-rules

explore

Codebase exploration toolkit. The gather-context skill primes new sessions by pulling state from multiple analysis tools.

Depends on: git-report memory · search-memories graphify codebase-index tree

memory

Persistent knowledge vault with QMD-powered semantic search. Stores lessons learned, ADRs, PDRs, and auto-captures session state.

Depends on: qmd graphify

codebase-index

Semantic code search via Ollama embeddings. Indexes code chunks, supports incremental updates, and provides call-graph analysis.

Depends on: ollama

devbot (agent)

Pair programming partner agent. At session start, primes context via gather-context and searches memory for relevant past learnings.

Depends on: agent-communication explore · gather-context memory · search-memory memory · remember-session

docs

Architecture documentation generators. Auto-generates use-case maps from PHP codebases and provides an interactive application map editor.

Depends on: graphify python3 · ast-grep
