## M-ARCH-041: Memory extraction should preserve both semantic search and human readability

recover-memories stores extracted knowledge in both Ogham (for agent search) and latent/ markdown files (for human review)
When building knowledge management systems, consider both machine and human access patterns. Semantic search enables agent retrieval, while structured markdown files enable human review and editing.
