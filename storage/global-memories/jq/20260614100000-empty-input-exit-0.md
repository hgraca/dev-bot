## jq returns exit 0 on empty input, not an error

Unlike Python's `json.loads()` which raises on empty/blank input, `jq '.'` with empty stdin returns exit 0 and produces no output. This is relevant when using `jq` in scripts or pipelines where input may be empty — piping to `jq` won't trigger error handling the way a JSON parser would. To detect empty/invalid JSON before `jq`, check input size or test parsing with a separate validation step (e.g. `jq empty` which exits 0 only if valid JSON is present).
