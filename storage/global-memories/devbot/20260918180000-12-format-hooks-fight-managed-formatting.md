## devbot's format-* file.edited hooks rewrite edited files and fight third-party-managed formatting

Editing a `.json` or `.yml` file with the Edit tool fires `format-json` / `format-yml`, which run prettier and rewrite the whole file — re-indenting it and collapsing or requoting values. On files owned by another tool (workflows and the `Makefile` regenerated by `get-e/dev-tools`, for example) this produces a diff that the next upstream regeneration flips straight back, and it silently undoes a deliberate choice to preserve existing style, such as `[ "sh", ... ]` spacing inside a YAML flow sequence. When a file's formatting is externally owned, make the change with a targeted write that does not emit `file.edited` (a small scripted edit), and re-read any file after an Edit that triggered a formatter before editing it again.
