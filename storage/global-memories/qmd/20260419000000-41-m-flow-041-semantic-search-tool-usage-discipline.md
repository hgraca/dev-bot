## M-FLOW-041: Semantic search tool usage discipline

Agent used only read/grep during implementation instead of codebase-index, ogham, qmd, graphify for discovery
Use read/grep only when exact file paths are known. Use semantic tools (codebase-index, ogham, qmd, graphify) when exploring, discovering patterns, or starting fresh - the token cost is small compared to missing something
