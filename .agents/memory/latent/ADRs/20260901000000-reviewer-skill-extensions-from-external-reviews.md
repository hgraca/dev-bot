## Reviewer skill extended from external-review gaps (SAML / Copilot)

After an external (GitHub Copilot) review of the positioning-activities ARC-808 SAML SSO change caught issues our reviewer missed, `review-implementation/SKILL.md` gained the distilled recurring issue types and the reviewer profile gained two behavioural MUSTs. Generic types: concurrent-race recovery must guard the actually-failing operation (Eloquent `new()` does not persist, so a 1062 catch around a non-persisting `create()` is dead code); a newly-gated admin capability needs a bootstrap path (a privilege flag defaulting false that gates the only admin API locks out the first admin). PHP: assumed third-party security defaults must be verified in the installed vendor code (onelogin strict mode does not imply `wantAssertionsSigned`); credentials must not be persisted raw (generated `Str::random` passwords). Laravel: case-sensitive identifiers need binary collation (`utf8mb4_bin`; the default `utf8mb4_unicode_ci` conflates case); single-use cache consumption must be atomic (`Cache::pull` is read-then-delete, so use a lock); route params must be constrained to value-object constructors (`whereUuid` → 404, not an `InvalidUuidException` 500); API resource serialization must be scalar (backed enums silently `json_encode` to `{}`, so resources use `->value` and response tests assert the serialized value); validation must be bounded to the DB schema (every validated string needs a `max` matching its column length, so oversized input fails 4xx instead of leaking a 500); a DB constraint-violation handler must map the violated key to the correct field rather than hardcoding one. The two behavioural MUSTs on the reviewer agent: proposed fixes must cover every variant/path of the issue (all error keys, branches, call sites), not just the reported case; and the reviewer must proactively verify library security defaults a change relies on, not merely the claims it asserts. Rationale: these are all silent-failure classes (wrong-but-working output, 500s from schema/validation drift, misleading error fields) that inspection-level checks now catch before an external review does.
