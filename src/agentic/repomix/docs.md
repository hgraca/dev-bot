---
title: "Repomix"
description: "Directory packing into a single structured file."
---

Packs many files into a single compressed context dump — useful for giving an agent full context of a directory at once.

## How agents use it

When an agent needs to understand a whole subsystem, Repomix packs all relevant files into one structured output, avoiding dozens of individual file reads.

## Configuration

No project configuration is required.
