Write a container build that is small, reproducible and cache-friendly.

## What it does

Ships the `dockerfile-authoring` skill: battle-tested patterns for production-grade Dockerfiles — base-image choice, layer ordering, multi-stage builds, and the traps that quietly make a build slow or non-reproducible.

## Configuration

No project configuration is required — the skill guides whatever Dockerfile a project ships.
