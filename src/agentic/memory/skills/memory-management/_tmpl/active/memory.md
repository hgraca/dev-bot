## Session — Memory Skills

### While working:

Recall from memory often:
Every time you find a problem/bug that you need to solve,
search your memory using the skill `search-memory`
to find previous analysis and solutions for that problem.

Use the `memory-management` when working with memories.

Use `thinking` for scratch files, drafts, and WIP notes as needed.

### Before context overflow or compaction:

Load the `remember-session` skill — saves working state, promotes learnings.
